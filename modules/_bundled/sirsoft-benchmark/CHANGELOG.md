# Changelog

## [0.2.6] - 2026-07-16

### Changed

- 대용량 검색을 기본 벤치에서 제외하고 명시할 때만 1 VU·1회로 실행하며, 제한형 검색 응답 메타데이터까지 검증하도록 개선
- 검색 안전장치 제공 버전에 맞춰 `sirsoft-board` 최소 버전을 1.1.3으로 상향

## [0.2.5] - 2026-07-16

### Changed

- 대량 게시글 적재가 끝나면 게시판별 작성자 검색 사전도 함께 동기화하도록 개선
- 작성자 검색 사전 테이블 제공 버전에 맞춰 `sirsoft-board` 최소 버전을 1.1.2로 상향
- 홈·게시판·통합검색·쇼핑몰의 튜닝 전후 응답시간과 서버 CPU를 같은 조건으로 비교하는 A/B 하네스 추가

## [0.2.4] - 2026-07-15

### Fixed

- 기존 더미 상품 설명에 남아 있던 이전 상품 코드를 현재 공개 라우트용 코드와 일치하도록 자동 동기화

## [0.2.3] - 2026-07-15

### Fixed

- 더미 상품 코드에서 공개 상품 라우트가 허용하지 않는 하이픈을 제거하고 16자리 영숫자 코드로 생성하도록 수정
- 기존 하이픈 포함 더미 상품 코드를 상품 ID와 연결 데이터를 유지한 채 새 형식으로 자동 변환
- 상품 검증과 초기화가 신구 벤치마크 상품 코드 형식을 모두 인식하도록 보강

## [0.2.2] - 2026-07-15

### Fixed

- 쇼핑몰 더미 생성 요청에서 빈 게시판 선택값이 게시판 전용 최소 개수 검증에 걸리는 문제 수정
- 게시판과 쇼핑몰의 배치·청크 허용값을 작업 유형별로 검증하도록 보강

## [0.2.1] - 2026-07-15

### Fixed

- 계층형 상품 분류 초기화 시 연쇄 삭제된 하위 분류까지 삭제 통계에 정확히 반영하도록 수정

## [0.2.0] - 2026-07-15

### Added

- 쇼핑몰 상품 500~200,000건과 계층형 분류, 브랜드, 기본 옵션을 큐 기반 벌크 작업으로 생성할 수 있도록 추가
- 작업별 20~100장 이미지 풀을 상품 이미지 행에서 재사용해 사진이 포함된 대용량 데이터셋을 제한된 디스크 사용량으로 생성
- 쇼핑몰 데이터셋 진행률, 검증, 중단, 재실행, 주문 참조 보호 초기화를 관리자 화면에 통합

## [0.1.3] - 2026-07-15

### Fixed

- 대량 생성 또는 초기화 완료 후 게시판 총건수와 최근글 등 파생 캐시가 즉시 갱신되도록 개선

## [0.1.2] - 2026-07-14

### Fixed

- 생성/재실행/초기화 잡이 서버 기본 큐 설정과 엇갈려도 `database` 워커로 정상 적재되도록 큐 연결과 청크 재디스패치를 명시

## [0.1.1] - 2026-07-14

### Changed

- 더미 적재 완료 후 선택 게시판의 게시글/댓글 카운트를 동기화하고 검증 결과를 작업 상세에 노출하도록 개선
- 큐 이름을 서버 기본 큐 설정에 맞춰 자동 해석하고, 필요하면 `BENCHMARK_QUEUE_NAME`으로 분리 지정할 수 있도록 개선
- 그누보드7 7.0.3 및 게시판 모듈 1.0.1 기준으로 버전 제약을 상향
